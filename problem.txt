Саме тому обидва меню синхронізуються автоматично: вони дивляться на один і той самий location.pathname



useLocation()
Він повертає інформацію про поточний маршрут.
const location = useLocation();
це {
  pathname: "/reset",
  search: "?token=abc123",
  hash: "",
  state: null
}
тому location.pathname Він поверне: /reset
selectedKeys={[location.pathname]}
і меню зрозуміє, що зараз активний маршрут /reset.

useSearchParams(); він працює тільки з тим, що після ?.
const [searchParams] = useSearchParams();
const token = searchParams.get("token");
Він подивиться сюди:
?token=abc123
і поверне:
abc123
Якщо URL такий
/profile?id=25&sort=new
то
const [searchParams] = useSearchParams();
searchParams.get("id");
поверне
25
а
searchParams.get("sort");
поверне
new
💡 Запам'ятати можна так:

useLocation() → де я зараз знаходжуся? (/profile, /login, /explore).
useSearchParams() → які параметри передали в URL? (token, id, page, sort).

Саме тому для підсвічування меню використовують useLocation(), 
а для відновлення пароля — useSearchParams(), 
бо токен передається як параметр після ?.

Зробила синхронізацію цих меню за дією, для цього додала в масив кей і стався збій.
